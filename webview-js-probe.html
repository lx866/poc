WebView JS 接口探测

在目标 App 的 WebView 中加载本页面后，会自动枚举 window 上通过 addJavascriptInterface 注入的原生接口，并以弹框形式列出接口面（接口名 / 方法 / native 标记 / 敏感方法高亮）。

使用说明与判定规则
  1. 启动 sootmcp web 服务后，本页面地址为 http://<host>:<port>/webview-js-probe。
  2. 通过 deeplink、URL 跳转、代理重写等方式让目标 App 的 WebView 加载本页面。
  3. 页面加载后自动扫描：遍历 window 自有属性，凡对象上存在 native 方法 （Function.prototype.toString 返回 [native code]）即判定为注入接口； 页面自定义的纯 JS 对象默认不列出。
  4. 额外探测一份常见桥名清单（AndroidBridge / JSBridge / dsBridge / WebViewJavascriptBridge 等）， 命中但无 native 方法的会标记为「常见桥名」，多为 JS 包装桥，需人工确认。
  5. 方法名命中敏感关键词（loadUrl / open / file / exec / shell / install / sms / location / cookie 等）会以红色高亮。
  6. URL 追加 ?auto=0 可关闭自动弹框。
